# 开发电脑修复验收清单

本清单是后续修复的验收要求，**以下项目均未在本轮完成验收**。实际缺陷和修改原因见[主报告](TEST-FEEDBACK-v2.2.1.zh-CN.md)。勾选时必须附本次最终安装包的实际记录，不能沿用旧版本结果。

## 填写方法

每项至少记录：安装包版本及构建标识、完整 CODESYS 版本与启动配置、设备和编译器版本、操作时间、请求编号、实际结果及证据路径。失败或未测试直接写明。正式“通过”须有对应对象读回、稳定可读的编译诊断和保存证据；仅返回已应用或错误计数为零不够。

保留当前工程和已有配置。故障注入、删除授权记录、时间变更等验证只在可恢复的隔离测试环境做；测试授权由合法签发流程提供。本清单不授权本次反馈电脑执行这些操作。

## T：模板与设备依赖（R1）

- [ ] **T01 完整支持清单。** 列出所有已知、实际安装及承诺支持的完整版本和启动配置；至少逐一处理 SP18 Patch 6、SP19 Patch 5、SP19 Patch 6。涉及 SP20 的支持声明必须明确对应版本和验证情况。
- [ ] **T02 原始模板有效。** 每个版本在对应开发软件中打开；设备、编译器、库和脚本组件均可用，初始工程编译无错误，警告逐项处理或说明。
- [ ] **T03 保存后仍有效。** 模板保存、关闭、重开后，读取到相同的依赖和最小结构，再次编译有效；不能只依靠开发软件内存状态。
- [ ] **T04 交付包验证。** 从最终安装包安装后通过公开 MCP 新建模板副本并编译；交付文件与开发时使用的文件一致，结果可追溯。
- [ ] **T05 干净环境验证。** 在另一台电脑或干净虚拟机重复安装和新建；缺少设备时明确指出设备及版本，不能误报模板可用或在业务编辑后才发现。
- [ ] **T06 没有匹配模板。** Manager 明确提示当前版本没有可用模板，能直接查看制作要求并通过文件选择设置；不静默使用相邻版本。
- [ ] **T07 自制模板成功路径。** 按唯一说明制作最小 `.project`，通过“选择模板文件→验证并使用”完成绑定；Agent 后续新建实际使用该文件。
- [ ] **T08 自制模板错误路径。** 错误版本、缺设备/库、不能编译、文件不存在或不可读时给具体原因；更换正确文件后能够恢复，无需修改索引或计算固定摘要。
- [ ] **T09 分版本保存。** 切换版本、重启 Manager 后，各版本仍使用自己的模板路径；所选版本与实际连接版本不一致时明确提醒。
- [ ] **T10 保护原件和目标文件。** 业务编辑仅作用于新建副本，不修改模板原件；已有目标工程不能被静默覆盖。
- [ ] **T11 保护当前会话。** 当前工程有未保存修改时，模板验证不能关闭、替换或保存该工程；没有安全验证条件时说明下一步。
- [ ] **T12 逐版本完整业务验证。** 每个承诺支持的模板均通过下方 A 组温控测试；版本差异及必要的设备/库安装步骤进入统一说明。

## E：异常恢复（R2）

- [ ] **E01 正常编译失败。** 缺设备或普通代码错误时返回可读的错误和实际编辑/编译/保存次数；不把明确的编译失败笼统丢为结果未知。
- [ ] **E02 无效消息对象。** 某条编译消息的对象位置失效时，其他消息及该条可取得的文本仍保留；诊断不完整被明确标记，不误报通过。
- [ ] **E03 重复查看稳定。** 连续查看同一请求，诊断内容和数量不重复增长，操作计数不变，不再次编辑、编译或保存。
- [ ] **E04 阻断有解释。** 原请求不确定时，说明阻断请求、工程、已知效果及恢复步骤；新请求不得无期限静默排队。
- [ ] **E05 可安全核对。** 状态查询可用；允许安全的受影响对象读取，或立即说明不能读取的理由及恢复入口，不制造无法执行的只读队列。
- [ ] **E06 有边界的恢复。** 核对原工程及原请求后可恢复工作；只处理相关失败记录，不要求清空整个数据目录，并保留故障证据。
- [ ] **E07 连接退出。** CODESYS 退出或连接断开后，Manager 与 MCP 能给稳定可理解的状态；原请求的查看不会无说明地反复关闭连接。
- [ ] **E08 重启与换工程。** 新连接、不同工程或服务重启不会自动重放旧编辑；旧请求不能误关联新工程。
- [ ] **E09 安全取消。** 未派发请求可取消，派发及工程操作计数为零；已执行请求不能伪装成安全撤销。
- [ ] **E10 输出和重试受控。** 诊断、日志和自动重试有合理上限；故障状态能收敛，不因反复观察导致记录不断膨胀。

## L：所有版本需授权（R3）

- [ ] **L01 全新安装无试用。** 没有授权时无法执行受控工程功能；任何首次调用都不自动赠送使用期限。
- [ ] **L02 有效正式授权。** 合法签发并匹配机器、期限的授权可正常使用；界面准确显示期限和状态。
- [ ] **L03 无效授权。** 缺失、过期、签名无效、机器不匹配和时间记录异常均明确拒绝受控操作，说明恢复方法。
- [ ] **L04 所有入口一致。** Manager、Agent 和直接公开 MCP 调用受同一判断约束，不能绕开界面按钮限制。
- [ ] **L05 删数据不赠送期限。** 在隔离环境删除 Manager 数据或切换数据目录后，仍须有效授权，不产生免费期。
- [ ] **L06 旧试用不延续。** 从旧版有效、过期或记录损坏的试用状态升级，均不能把旧试用变成正式授权或重建免费期。
- [ ] **L07 重装与丢失记录。** 重装、升级及授权相关记录缺失不会恢复免费使用；有效正式授权是否保留须符合明确说明。
- [ ] **L08 管理恢复入口可用。** 未授权仍可查看状态、读取申请信息、导入授权和查阅说明/诊断，不陷入无法激活的循环。
- [ ] **L09 密钥和到期行为。** 安装包不含签发私钥；验证所需的公钥受程序信任规则保护。到期拒绝新的受控操作，不强行关闭 IDE、丢弃工程或停止已运行 PLC。
- [ ] **L10 发布一致性。** 所有本次发布渠道和安装形式使用取消试用的同一逻辑；旧下载包的处理、适用版本和升级说明明确，不能把新版行为冒称为旧版已远程修复。

## D：唯一图文使用说明（R4）

- [ ] **D01 一份操作正文。** 安装包和 Manager 只有一份完整用户操作说明；帮助入口跳到同一文件章节，不维护相互冲突的多份正文。
- [ ] **D02 顺序完全一致。** 按 01 功能介绍、02 安装和其他环境、03 CODESYS 版本与脚本/Trace 包、04 启动与脚本添加、05 Agent 接入、06 其他内容排列。
- [ ] **D03 环境要求准确。** 区分随包组件、系统要求和必须另装的 CODESYS 组件；版本支持与已知限制有明确证据。
- [ ] **D04 模板步骤完整。** 包含缺模板提示、最小工程制作要求、路径选择、验证成功和失败示例，与真实界面一致。
- [ ] **D05 图片对应实际操作。** 组件、版本、模板、脚本快捷方式、Agent 登录/信任、授权、恢复均有对应截图和正常结果；不使用伪造或未标识的旧界面。
- [ ] **D06 两客户端独立说明。** 分清 Codex、WorkBuddy 的桌面和命令行步骤，说明加载、登录和实际工具调用；不以工具发现代替工程测试。
- [ ] **D07 授权与恢复一致。** 清除全部“自动免费 30 天”等过时操作说明；公钥作用、授权导入、请求恢复及工程保护与程序行为一致。
- [ ] **D08 从头照做。** 由未参与开发的人在干净环境，仅凭这一份离线说明完成安装、授权、模板、连接和示例工程；记录不能独立完成的步骤并修订。

## A：Codex 与 WorkBuddy 各自完成温控工程

本组对两个 Agent **分别执行并保存证据**。只复制一个工程或只调用底层协议探测不能替代真实 Agent 测试。

- [ ] **A01 实际接入。** 登录及加载成功，真实 Agent 调用状态工具；记录实际连接版本和选中版本一致。
- [ ] **A02 独立新建。** 通过正式公开 MCP 从已验证模板创建各自工程；新建后基础编译通过，两个工程路径不同。
- [ ] **A03 官方 PID。** 库管理器中解析到官方 Util 库；程序实际声明并调用 `Util.PID_FIXCYCLE`，不以自编算法代替。记录实际库版本。
- [ ] **A04 周期一致。** 循环任务为 10ms，业务程序每周期只调用一次；官方功能块的固定周期参数为 `CYCLE := 0.01` 秒。
- [ ] **A05 曲线配置。** 目标温度、反馈温度、输出百分比均绑定到真实变量；温度同图、输出独立刻度 0–100，读取结果与提交一致。
- [ ] **A06 全部读回。** 库、两个程序对象、任务周期、调用关系、三个曲线变量均完整读回；字段失败不能由界面或临时私有脚本补做后冒充 MCP 通过。
- [ ] **A07 编译与落盘。** 编译诊断完整且稳定，零错误、警告有处理说明，保存成功；重开读取和必要复编译确认磁盘工程确为最终结果。
- [ ] **A08 准确报告覆盖。** 分别写明工程创建、编译保存、曲线配置和运行采集的结果。若公开能力仍不支持在线运行/采集，应明确写未验证，不把离线配置写成实时温控曲线通过。

提交修复时附上源码提交、最终安装包、逐版本矩阵、上述结果与证据链接、唯一图文说明和剩余限制。反馈中留存的两份 `.st` 代码标为未验收，不能当作本清单的完成证明。
